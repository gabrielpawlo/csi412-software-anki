# csi412-software-anki

Trabalho prático "Software archaeology" da disciplina CSI412 – Engenharia de Software I (UFOP, semestre 2026/2, Prof. Igor Muzetti Pereira).

## Integrantes

- [Gabriel Guimarães Pawlowski]
- [Carlos Eduardo Barçante Gomes]

## Software analisado

Anki, um programa livre de cartões de memorização (flashcards) que usa repetição espaçada. A análise considera a release 26.09.3 (tag `26.09.3`, commit `29bb700`).

## Link para o projeto original

https://github.com/ankitects/anki

## Objetivo do trabalho

Investigar e compreender o Anki a partir de evidências reais do projeto (código-fonte, documentação, issues, pull requests, commits e releases), reconstruir parte dos seus requisitos e propor uma pequena evolução, de modo a justificar tecnicamente uma mudança no sistema.
